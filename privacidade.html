Além da Animação

Política de privacidade

Vigente desde 19 de novembro de 2026. A versão anterior, de 18 de novembro de 2026, tratava só do YouTube.

Resumo

O Além da Animação é um programa pessoal instalado no computador do próprio usuário. Os dados do YouTube, do TikTok e do Telegram que ele acessa ficam nesse computador e são usados só para publicar e acompanhar os vídeos do próprio usuário. Nada é enviado ao desenvolvedor, vendido ou compartilhado com terceiros.

Serviços usados

  • YouTube: o programa usa os Serviços de API do YouTube. Ao conectar um canal, você concorda com os Termos de Serviço do YouTube, e os dados tratados pelo Google seguem a Política de Privacidade do Google.
  • TikTok: o programa usa o Login Kit e a Display API do TikTok for Developers. Ao conectar uma conta, você concorda com os Termos de Serviço do TikTok, e os dados tratados pelo TikTok seguem a Política de Privacidade do TikTok.
  • Telegram: o programa usa a Bot API do Telegram, com um bot criado pelo próprio usuário, para mandar avisos ao celular dele. As mensagens seguem a Política de Privacidade do Telegram.

Quais dados são acessados

YouTube

  • Dados do canal: ID, nome, identificador (@) e imagem do canal autorizado, para mostrar qual conta está conectada.
  • Vídeos: os arquivos que o próprio usuário escolhe, com título, descrição e data de publicação, para enviar e agendar no canal.
  • Estatísticas: visualizações e outras métricas do canal e dos vídeos enviados, pela YouTube Analytics API, para mostrar resultados e melhores horários dentro do programa.

TikTok

  • Perfil básico: ID da conta para este app (open ID), nome de exibição e imagem da conta autorizada, para mostrar qual conta está conectada.
  • Vídeos públicos da conta: ID, legenda, data de publicação, duração, imagem de capa e as contagens de visualizações, curtidas, comentários e compartilhamentos, para confirmar que um vídeo agendado foi publicado e mostrar os resultados dentro do programa.

O programa não publica, não edita e não apaga vídeos no TikTok. A publicação é feita pelo próprio usuário, no aplicativo do TikTok.

Telegram

  • Conversa com o bot: o ID da conversa entre o usuário e o bot dele, para saber para onde mandar as mensagens, e os toques nos botões dessas mensagens (por exemplo, "Publiquei").
  • O que é enviado: o vídeo agendado, a legenda, o horário combinado e os lembretes, sempre para a conversa do próprio usuário.

Chaves de acesso

  • Os tokens de autorização emitidos pelo Google e pelo TikTok, para o programa agir em nome da conta, e o token do bot do Telegram, criado pelo próprio usuário.

O programa não acessa e-mail, contatos, mensagens diretas, histórico de navegação nem dados de outras pessoas.

Onde os dados ficam

  • Em um banco de dados local no computador do usuário. Não há servidor do desenvolvedor.
  • Os tokens de autorização e o token do bot são guardados criptografados, com uma chave protegida pelo próprio Windows.
  • As cópias de segurança são locais, criptografadas e ficam em um disco do mesmo computador.
  • Os vídeos e as legendas mandados ao Telegram ficam na conversa do usuário com o bot, nos servidores do Telegram, até o usuário apagá-los.
  • O programa só se comunica com os serviços oficiais do Google, do YouTube, do TikTok e do Telegram.

Por quanto tempo

Os dados ficam no computador enquanto a conta estiver conectada. Ao desconectar uma conta no programa, a autorização é revogada na plataforma e os tokens e os dados dessa conta são apagados do computador na mesma hora. Ao remover o bot do Telegram no programa, o token dele é apagado.

Como revogar o acesso

  • No programa: página Contas, botão Desconectar.
  • Pelo Google, a qualquer momento: configurações de segurança da sua Conta do Google, removendo o acesso do Além da Animação.
  • Pelo TikTok, a qualquer momento: no aplicativo, nas configurações de segurança e permissões, removendo o Além da Animação da lista de apps com acesso à conta.
  • Pelo Telegram, a qualquer momento: bloqueando o bot, ou excluindo-o pelo @BotFather.

Cookies e rastreamento

Este site não usa cookies nem ferramentas de análise. O programa não usa rastreamento nem publicidade.

Mudanças

Se o programa passar a usar outros dados ou outros serviços, esta página será atualizada antes, com a nova data de vigência.
