Além da Animação

Política de privacidade

Vigente desde 18 de novembro de 2026.

Resumo

O Além da Animação é um programa pessoal instalado no computador do próprio usuário. Os dados do YouTube que ele acessa ficam nesse computador e são usados só para publicar e acompanhar os vídeos do próprio usuário. Nada é enviado ao desenvolvedor, vendido ou compartilhado com terceiros.

Serviços de API do YouTube

O programa usa os Serviços de API do YouTube. Ao conectar um canal, você concorda com os Termos de Serviço do YouTube, e os dados tratados pelo Google seguem a Política de Privacidade do Google.

Quais dados são acessados

  • Dados do canal: ID, nome, identificador (@) e imagem do canal autorizado, para mostrar qual conta está conectada.
  • Vídeos: os arquivos que o próprio usuário escolhe, com título, descrição e data de publicação, para enviar e agendar no canal.
  • Estatísticas: visualizações e outras métricas do canal e dos vídeos enviados, pela YouTube Analytics API, para mostrar resultados e melhores horários dentro do programa.
  • Chaves de acesso: os tokens de autorização emitidos pelo Google, para o programa agir em nome do canal.

O programa não acessa e-mail, contatos, histórico de navegação nem dados de outras pessoas.

Onde os dados ficam

  • Em um banco de dados local no computador do usuário. Não há servidor do desenvolvedor.
  • Os tokens de autorização são guardados criptografados, com uma chave protegida pelo próprio Windows.
  • As cópias de segurança são locais, criptografadas e ficam em um disco do mesmo computador.
  • O programa só se comunica com os serviços oficiais do Google e do YouTube.

Por quanto tempo

Os dados ficam no computador enquanto a conta estiver conectada. Ao desconectar a conta no programa, a autorização é revogada no Google e os tokens são apagados do computador na mesma hora.

Como revogar o acesso

  • No programa: página Contas, botão Desconectar.
  • Pelo Google, a qualquer momento: configurações de segurança da sua Conta do Google, removendo o acesso do Além da Animação.

Cookies e rastreamento

Este site não usa cookies nem ferramentas de análise. O programa não usa rastreamento nem publicidade.

Mudanças

Se o programa passar a usar outros dados ou outros serviços, esta página será atualizada antes, com a nova data de vigência.
